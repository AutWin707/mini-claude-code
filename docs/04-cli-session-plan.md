# 第 4 章：CLI 与会话方案记录

> 方案记录，暂不实现代码。

## CLI 入口

- 有 prompt：直接调用 `agent.chat(prompt)`，完成后退出，不启动 REPL。
- 没有 prompt：进入 React + Ink 实现的交互式 REPL。
- 启动工作目录为执行命令时所在的目录。
- 模型由 `.env` 或环境变量中的 `ANTHROPIC_MODEL` 指定，不设默认值。

## REPL 本期范围

只实现聊天、切换会话、clear、compact，以及显示 token 使用数量；不扩展其他交互功能。

### chat：发送消息

- 用户输入聊天内容后调用当前会话的 `agent.chat()`。
- 后续输入沿用当前会话的消息、模型配置和工具状态，不为每条输入创建新会话。
- 输入与工具调用循环产生的消息、工具调用及结果写入当前会话 JSONL。
- 命令拼写暂按 `/chat <内容>`，普通文本输入也作为聊天内容发送。

### 切换会话

- 进入 REPL 时默认开始新会话。
- 输入框为空时按左箭头打开会话列表；有文字时左箭头用于移动光标。
- 列表不按项目过滤，显示会话概略；上下键选择，回车切换。
- 切换时恢复所选会话的记录和配置，并切换到记录中的工作目录，继续原来的对话。
- 恢复的工作目录不存在时应提示用户，不应静默切换到其他目录。

### clear：只清屏

- `/clear` 只清除当前界面的聊天/输出显示区域，保留输入区域与状态显示。
- 不创建新会话、不切换会话，当前会话 UUID 不变。
- 不清空 Agent 的对话上下文或工具状态，下一条消息仍继续原来的对话。
- 不删除、截断或改写 JSONL 中的对话内容。
- 不重置 token 使用统计。

### compact：压缩上下文

- `/compact` 压缩当前会话送给模型的上下文，区别于只影响显示的 `/clear`。
- 初步方案：使用当前模型生成上下文摘要，保留继续任务所需的信息，以摘要替换较早的活动上下文。
- 压缩不创建或切换会话，不删除原始 JSONL 历史；追加压缩摘要和生效范围记录。
- 恢复会话时根据最近一次成功的压缩记录重建活动上下文，再接上后续消息；不把已压缩的旧消息再次全部发给模型。
- 压缩失败时保留原上下文，不写入成功压缩记录。
- 压缩摘要用于继续对话，与会话列表展示的“概略”分开存储。

### token 使用数量

- 显示最近一轮及当前会话累计的输入、输出 token 数量。
- 以模型 API 返回的 usage 为准；一轮中多次模型调用（包括工具循环）的 usage 需要累加。
- 概略生成和 compact 的模型调用也计入会话累计使用量。
- usage 随会话持久化，切换会话时恢复该会话的统计，不混用其他会话的数据。
- clear 不重置统计；compact 不减少历史累计用量。累计用量不等于当前上下文大小。
- API 未提供 usage 时显示不可用，不伪造为 0；缓存相关字段的展示按实际 API 返回值再确定。

## 会话存储与概略

- 会话使用 JSONL 存储，目录为 `~/.mini-claude/sessions/`；每个会话使用 UUID 标识，文件名为 `<UUID>.jsonl`。
- JSONL 记录继续对话所需的信息，包括工作目录、消息、工具调用与结果、模型配置、概略、压缩记录和 token usage；API key 等密钥不写入会话文件。
- 使用当前对话模型，在首轮对话结束后生成一次概略，写入对应的 JSONL；后续不自动更新。
- 概略生成失败后最多重试 3 次；仍失败则写入一个不重复的兜底名称，可包含完整会话 UUID。
- JSONL 按顺序追加记录，不引入消息分支。恢复会话不会回滚项目文件内容。

## 实现时待细化

- 明确 chat、clear、compact 的命令解析和快捷键；上面的 `/chat`、`/clear`、`/compact` 暂作为命令形式。
- 确定 compact 保留最近多少消息、摘要格式及压缩生效范围的记录结构；不得拆散工具调用与结果的配对。
- 确定 JSONL 事件结构与追加时机；恢复时忽略未写完的末尾记录，并在后续追加前修复文件。
- 模型请求或工具执行期间，先禁止重复提交、切换会话和 compact，避免并发修改同一会话。
- 单次 prompt 模式是否持久化会话、如何展示 usage，留待实现前确认；无论如何都不启动 REPL。

## 验收重点

- 有 prompt 只执行一次 `agent.chat(prompt)`；无 prompt 才启动 REPL。
- chat 能连续对话，切换会话后恢复对应上下文、配置、工作目录及 token 统计。
- clear 前后会话 UUID、内存对话、工具状态、JSONL 内容和 token 统计保持不变，仅显示区域被清除。
- compact 成功后活动上下文缩短、原始历史仍保留；重启恢复后的上下文与压缩后的一致。
- compact 失败不丢失上下文；token 数量按真实 usage 累加，不因清屏或压缩而归零。
